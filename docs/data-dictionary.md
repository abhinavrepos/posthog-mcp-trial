Columns: event, timestamp (UTC; use end-exclusive ranges), distinct_id, person_id; session: $session_id / properties.$session_id. Person fields: person.properties.*.

distinct_id format: ENV|01|C123|user1; separator "|". User is part 4 (1-based).

Client is part 3 (1-based) of distinct_id: splitByChar('|', distinct_id)[3]; Lens client dimension uses this instead of the property.

Identity examples are placeholders, not live identities.

SQL: alias count() AS events_count so privacy keeps counts.

Retention uses retentionFilter.targetEntity and returningEntity with {id: <event>, name: <event>, type: "events"}; event property filters belong in top-level properties. aggregate_events accepts group_by and filters.dimension using the Lens names above; control, title, client_name and $time have no aggregate dimension. Not every event fills every property.
